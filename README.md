# Siam Islam — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive layout, colors, animations and light theme
- `script.js` — mobile navigation, theme persistence, reveal animations and email form

## Before publishing
1. Open `script.js`.
2. Replace `YOUR_EMAIL@example.com` with your real public contact email.
3. In `index.html`, update the bio, skill levels, project descriptions and project links.
4. Add your own profile photo if you want one (the current hero uses initials "SI").

## Contact form
The form uses a `mailto:` link. It opens the visitor's configured email application; it does not send or store messages automatically. For a hosted form with no visitor email app requirement, connect a form service or backend later.

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## Publish with GitHub Pages
In your repository, go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save. Wait for the deployment to finish.
